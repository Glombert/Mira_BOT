# Дизайн-направление Mira

Визуальный язык для всех клиентов: web, desktop, mobile. Один характер, разные платформенные привычки.

## Концепция

**Тёплая темнота.** Мира названа в честь переменной звезды Mira (omikron Ceti) — холодный красный гигант, который пульсирует от едва видимой до яркой. Палитра берёт эту звезду как метафору: глубокий тёмный космос как фон + тёплый янтарный/амбра как живой акцент.

Это не "корпоративный dark mode" с холодным синим — это **тёплый dark** с уходом в коричнево-чёрный, чтобы оранжевые акценты не выглядели чужеродными.

## Типографика

### Шрифты

- **Основной:** Inter (latin + cyrillic). Кириллица обязательна, без неё всё развалится.
- **Технический:** JetBrains Mono — только для кода, ID, file paths. Не для UI-текста.
- **Подключение:** через `next/font` (web) или `expo-font` (mobile), не CDN.

### Шкала

| Размер | px | line-height | Назначение |
|---|---|---|---|
| `text-xs` | 12 | 16 | Метаданные, timestamp |
| `text-sm` | 14 | 20 | Подписи, кнопки второстепенные |
| `text-base` | 15 | 24 | Сообщения в чате — главный размер |
| `text-lg` | 17 | 26 | Заголовки модалок |
| `text-xl` | 20 | 28 | Имя пользователя в шапке |
| `text-2xl` | 24 | 32 | Большие заголовки экранов |

Базовый размер чуть больше обычных 14px — чтобы читать переписку с Мирой было приятно, не приходилось щуриться.

### Вес

- 400 (regular) — основной
- 500 (medium) — кнопки, активные элементы
- 600 (semibold) — заголовки

Без bold (700+). Без italic (кроме случаев когда это код в `<em>`).

## Компоненты — общие правила

### Скругления

- Карточки сообщений, модалки: `12-16px`
- Кнопки: `8px`
- Поля ввода: `8px`
- Аватары: круглые

Никаких острых углов. Никаких pill-кнопок (полностью круглых) кроме иконочных.

### Тени

Тени используем мягкие и **тёплые** (с оттенком акцента), а не чёрные:

```css
--shadow-soft: 0 2px 8px rgba(0, 0, 0, 0.3), 0 0 1px rgba(255, 140, 66, 0.06);
--shadow-elevated: 0 8px 24px rgba(0, 0, 0, 0.4), 0 0 2px rgba(255, 140, 66, 0.08);
--shadow-glow: 0 0 24px rgba(255, 140, 66, 0.18); /* для активных кнопок */
```

### Отступы

Tailwind spacing scale, но придерживайся ритма:
- Между сообщениями: `12px` (`gap-3`)
- Внутренние отступы карточек: `16px` (`p-4`)
- Между секциями: `24px` (`gap-6`)
- Внешние поля контейнера: `16px` на мобильном, `24px` на десктопе

### Анимации

Все длительности — короткие, без bounce:

```css
--duration-fast: 120ms;     /* hover, focus */
--duration-normal: 200ms;   /* появление сообщений, открытие модалок */
--duration-slow: 320ms;     /* переходы между экранами */
--easing: cubic-bezier(0.2, 0.0, 0.2, 1);
```

Анимации для:
- Появление сообщения: `opacity 0→1 + translateY(4px→0)` за 200ms
- Hover на кнопке: `background-color` 120ms
- Индикатор "думает" (`thinking`): пульсация opacity `0.4 ↔ 1.0` каждые 1.4s

## Экранные паттерны

### Сообщения в чате

Два визуально разных бабла:

**Сообщение пользователя** (выровнено вправо):
- Фон: `--bg-elevated`
- Текст: `--text-primary`
- Скругление: `16px 16px 4px 16px` (заусенец справа внизу)
- Max-width: 70% контейнера

**Сообщение Миры** (выровнено влево, с аватаром):
- Аватар — звезда (см. ниже)
- Фон: прозрачный или `--bg-elevated` тонкого
- Имя "Мира" сверху мелким `--text-secondary`
- Текст: `--text-primary`, размер `text-base`
- Markdown rendered: код-блоки в `JetBrains Mono` на `--bg-overlay`, ссылки в `--accent`

**Системное сообщение** (по центру или приглушённо слева):
- Без аватара
- Фон: прозрачный
- Текст: `--text-secondary`, размер `text-sm`
- Иконка (lucide: `Info`, `AlertCircle`, `Check`) того же цвета что текст
- Отступы меньше обычного бабла

**Ошибка**:
- То же что system, но иконка и текст в `--error`

### Аватар Миры

Иконка-звезда. Варианты:
1. SVG-звезда с 4 лучами, заполненная градиентом `--accent → --accent-soft`
2. Или просто символ `★` в кружке `--bg-elevated` с цветом `--accent`

Сделай первый вариант — узнаваемее. Размер аватара: 28px рядом с сообщениями, 40px в шапке.

### Шапка приложения

- Слева: аватар Миры (40px) + название "Мира" 
- В центре: ничего (или статус соединения)
- Справа: индикатор подключения + имя пользователя + меню

Индикатор подключения — точка:
- `--success` (зелёная) — WS connected
- `--warning` — reconnecting
- `--text-muted` — offline

### Поле ввода

- Фон `--bg-input`, граница `--border-default`
- При фокусе: граница `--accent`, тень `--shadow-glow` (мягкая)
- Слева кнопка-скрепка (загрузка файла)
- Справа: кнопка-самолётик (отправить) — активна только когда есть текст
- Auto-resize textarea — растёт до 6 строк, потом скролл

### Команды

Не все пользователи готовы помнить `/remind 2026-05-20T09:00 утренний кофе`. Делай **палитру команд** (как Cmd+K в Linear):

- Кнопка-меню в шапке или Ctrl/Cmd+K
- Список всех команд из API.md раздела 3
- Каждая — иконка + название + краткое описание
- Клик → открывается мини-форма (для `remind` — дата-пикер + текст; для `gdrive_get` — поле ID; и т.д.)
- Форма генерирует команду в правильном синтаксисе и шлёт через `sendCommand`

## Иконки

`lucide-react` (web/desktop) и `lucide-react-native` (mobile). Использовать одни и те же имена:
- Меню: `Menu`
- Загрузка файла: `Paperclip`
- Отправить: `Send` или `ArrowUp`
- Файлы: `Folder`, `FileText`, `FileSpreadsheet`
- Календарь: `Calendar`
- Drive: `Cloud`
- Напоминание: `Bell`
- Профиль: `User`
- Настройки: `Settings`
- Ошибка: `AlertCircle`
- Успех: `Check`
- Загрузка: `Loader2` (с `animate-spin`)

Размер: 16px в подписях, 20px в кнопках, 24px в шапке.

## Мобильные особенности (RN)

- Bottom sheet вместо модалок на телефоне
- Свайп влево по сообщению → копировать / поделиться
- Native pull-to-refresh **отключить** в чате — там WS, всё real-time
- При открытии клавиатуры — скролл к последнему сообщению + поле ввода поднимается над клавой
- Splash screen на запуске: чёрный фон + звезда-аватар по центру

## Доступность

- Контраст текста ≥ AA (WCAG): `--text-primary` на `--bg-base` даёт 11.5:1 — с запасом
- Минимальный размер кликабельных элементов: 44x44px на мобильном, 36x36px на десктопе
- Все иконочные кнопки имеют `aria-label` (web) или `accessibilityLabel` (RN)
- Поддержка клавиатурной навигации в вебе: Tab по всем интерактивным элементам, Enter — отправить, Esc — закрыть модалку
- `prefers-reduced-motion` — выключает анимации появления сообщений

## Чего избегать

- ❌ Чисто-чёрный фон `#000000` — будет резать глаз с тёплыми акцентами
- ❌ Холодные синие/серые в палитре — нарушит характер
- ❌ Glassmorphism (`backdrop-filter: blur`) — для интимного инструмента это слишком "облако"
- ❌ Параллакс при скролле — отвлекает от текста
- ❌ Видеофоны и градиентные обои
- ❌ "Кричащие" анимации — пружины, отскоки, тряска
- ❌ Toast-уведомления в углу для всего — `system` сообщения идут прямо в чат
