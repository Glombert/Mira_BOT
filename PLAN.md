# Mira — Дорожная карта

> Обновлено: 2026-06-11. Что **сделано** — подробно в `WHATS_NEW.md`;
> как устроено — в `ARCHITECTURE.md`. Здесь только крупные вехи и что впереди.

---

## Сделано (крупными мазками)

- **Ядро агента** — класс `Agent`, 40 инструментов, failover-цепочка
  провайдеров, prompt caching, Конклав специалистов с QA-циклом.
- **Интерфейсы** — Telegram-бот, веб (FastAPI + WebSocket + Next.js),
  десктоп (Tauri), мобайл (React Native APK через CI). Один диалог сквозь все.
- **Память** — SQLite (`mira.db`), семантический recall (ChromaDB),
  суммаризация, Fernet-шифрование, persona overlay.
- **Самость** — self-edit персоны, `/evolve` (саморедактирование кода под
  PRINCIPLES), фоновые ритуалы (здоровье сервера, аудит логов, само-ревью,
  слежение за моделями), технический канал владельца.
- **Дизайн Aurora** — единый визуальный язык (полночь+золото) на вебе и мобайле.
- **Инфраструктура** — VPS Амстердам + РУ-мост, WireGuard/Reality VPN,
  мониторинг сервера и VPN с графиками в owner-меню, Bugsink-наблюдаемость.
- **Здоровье кода** — пути через `PROJECT_ROOT`, ядро разнесено по
  `core/bot/web`, ruff в pre-commit, 453+ тестов, парити-тест WS-контракта.

---

## Впереди (кандидаты, не обязательства)

- **Учёт Reality-пользователей** — у VPN-экрана пока только WireGuard-пиры;
  для гостей на Hiddify/vless нужен сбор статистики из sing-box.
- **`web/app.py`** ещё ~1000 строк (роуты + WS-цикл чата) — WS-цикл можно
  вынести отдельным модулем, если файл продолжит расти.
- **Латентность в метриках** — на экране «Метрики LLM» поле задержки пока «—».
- **Больше ритуалов-скриптов** — детерминированные проверки без траты токенов.

## Принципы развития

- Работаем в ветке `mira-dev`, не в `main`. Деплой только оттуда.
- Каждая новая фича → запись в `WHATS_NEW.md` (Мира читает его сама).
- Перед коммитом — `venv/bin/pytest -q` зелёный. Тесты не маркируем `skip`.
- Тяжёлые сборки (Android, native) — только через CI, не локально.
- Полный свод рабочих правил — в `CLAUDE.md`.
